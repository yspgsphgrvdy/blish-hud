## 🕹️ Overview

Blish HUD is an overlay framework for Guild Wars 2 that loads community-created modules to display maps, timers, markers, and much more while you play.

Whether you're a newcomer or a veteran, Blish HUD provides the tools you need to get the most out of your gaming tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.
